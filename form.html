Panduan Integrasi Google Drive (3 Langkah Mudah)

Ikuti panduan berikut untuk membuat webhook Google Apps Script gratis agar setiap responden dapat mengunggah file (PDF, Word, Excel, Foto) langsung ke folder Google Drive Anda tanpa perlu login akun Google:

1

Buka Google Apps Script

Kunjungi script.google.com di browser Anda, lalu klik tombol "New Project" (+ Proyek Baru).

2

Tempelkan Kode Skrip Webhook

Hapus seluruh kode bawaan di editor Apps Script (Code.gs), lalu tempelkan kode di bawah ini:

// Memuat kode webhook...
3

Deploy sebagai Web App

  • Klik tombol biru "Deploy" di pojok kanan atas > Pilih "New deployment".
  • Pilih tipe: "Web App" (ikon gear).
  • Isi Description: FORM Upload Webhook.
  • Execute as: Pilih "Me" (Akun Google Anda).
  • Who has access: Wajib pilih "Anyone" (Siapa saja) agar responden bisa upload.
  • Klik Deploy > Berikan izin (Authorize access).
  • Salin "Web App URL" yang berakhiran /exec lalu tempelkan di kolom input Google Drive di formGenerator-IskakFatoni.
💡 Cara Mendapatkan ID Folder Google Drive (Opsional):
Buka folder di drive.google.com, perhatikan URL di browser Anda:
https://drive.google.com/drive/folders/1a2B3c4D5e6F7g8H9i0J
Teks tebal di atas adalah ID Foldernya.
